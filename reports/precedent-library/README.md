# Precedent Library

Pre-digested vulnerability patterns organized by class. Each file contains:
- Common manifestations of the bug class
- Known bypass techniques for common defenses
- Historical CVE references for the pattern
- Chain opportunities (what this class commonly chains with)

## Files
- `sqli.md` — SQL injection patterns and bypasses
- `xss.md` — XSS patterns, contexts, and filter bypasses
- `ssrf.md` — SSRF patterns, filter bypasses, and cloud metadata paths
- `auth.md` — Authentication and authorization bypass patterns
- `deser.md` — Deserialization gadget chains by framework
- `privesc-windows.md` — Windows privilege escalation patterns

Files are added as the knowledge base grows through processed intake and engagement experience.
